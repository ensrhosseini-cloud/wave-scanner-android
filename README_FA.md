# WaveScanner Futures — نسخهٔ اندروید ۲٫۰

## وضعیت واقعی تحویل
این بسته **سورس نسخهٔ اندروید** است، نه APK آمادهٔ نصب. هسته و مدیریت اسکن با تست خودکار بررسی شده‌اند؛ اما رابط Kivy در محیط تحویل اجرا نشده و ساخت APK، نصب روی گوشی، فارسی‌نمایی و ذخیره‌سازی اندروید هنوز تأیید نشده‌اند. Java، Android SDK/NDK و Buildozer در محیط تحویل موجود نبودند. نصب وابستگی‌های رابط نیز در مهلت تعیین‌شده کامل نشد.

## امکانات پیاده‌سازی‌شده
- رابط موبایل فارسی با فونت همراه و راست‌به‌چپ‌سازی متن‌های ثابت.
- فقط API عمومی KuCoin Futures؛ قراردادهای دائمی خطی USDT، بدون دادهٔ اسپات، کلید معاملاتی یا ارسال سفارش.
- سیگنال از کندل **بسته‌شدهٔ ۱ساعته** و تأیید روند از کندل **بسته‌شدهٔ ۴ساعته**؛ تایم‌فریم‌ها ثابت‌اند.
- چهار گروه لانگ فعال، آمادهٔ لانگ، شورت فعال و آمادهٔ شورت؛ بدون سقف تعداد نتایج.
- نمایش پیشرفت، توقف، تفکیک پوشش ناقص از نتیجهٔ منفی، و جزئیات هر نماد با لمس آن.
- تنظیم گردش، هدف حرکت قیمت، حداقل R/R، ضریب حجم، سقف اسپرد و جهت اسکن؛ اعداد فارسی هم پذیرفته می‌شوند.
- خروجی UTF-8 در TXT و JSON. در اندروید با انتخابگر فایل سیستم، بدون درخواست دسترسی کلی به حافظه؛ کپی آخرین گزارش در فضای خصوصی برنامه ذخیره می‌شود.
- اسکن در نخ جداگانه انجام می‌شود. با رفتن به پس‌زمینه، درخواست توقف ارسال می‌شود؛ توقف ممکن است تا پایان درخواست شبکه طول بکشد. سرویس پس‌زمینه، اعلان، اجرای خودکار یا تضمین ادامهٔ اسکن هنگام قفل گوشی وجود ندارد.

## ساخت APK با GitHub Actions
1. تمام محتوای این پوشه، **از جمله `.github`**، را در ریشهٔ یک مخزن GitHub قرار دهید. هیچ کلید صرافی لازم نیست.
2. در تب **Actions**، گردش‌کار **Build Android debug APK** را انتخاب کنید.
3. روی **Run workflow** بزنید و تا پایان موفق ساخت صبر کنید.
4. از بخش Artifacts، بستهٔ `WaveScanner-Android-debug` را دانلود و ZIP آن را باز کنید.
5. تنها اگر ساخت موفق شده باشد، فایل APK داخل آن قرار دارد. آن را به گوشی منتقل کنید و نصب از همان منبع را در صورت نیاز مجاز کنید.

این گردش‌کار هنوز در این پروژه اجرا/تأیید نشده و ممکن است نیازمند اصلاح نسخه‌های ابزار یا recipeهای python-for-android باشد، خصوصاً NumPy و pandas. اگر اجرا خطا داد، لاگ ساخت مبنای رفع مشکل است؛ وجود این فایل به معنی تولیدشدن APK نیست. خروجی debug مناسب آزمایش است، نه انتشار فروشگاهی یا نسخهٔ امضاشدهٔ نهایی.

## ساخت محلی در Linux یا WSL2
پیشنهاد: Ubuntu 22.04، Python 3.11 و JDK 17. برای WSL پروژه را در فایل‌سیستم لینوکسی قرار دهید. چندین گیگابایت فضای آزاد و اینترنت برای دریافت SDK/NDK لازم است.

```bash
sudo apt-get update
sudo apt-get install -y openjdk-17-jdk git zip unzip autoconf automake libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev cmake libffi-dev libssl-dev python3-venv
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install buildozer==1.5.0 Cython==0.29.36 setuptools
buildozer android debug
```

APK موفق در `bin/` ایجاد می‌شود. مشخصات فعلی: Android 7/API 24 یا بالاتر، پردازندهٔ **arm64-v8a**، هدف API 35. این تنظیم به معنی آزمون روی همهٔ نسخه‌ها نیست؛ گوشی‌های صرفاً ۳۲بیتی پشتیبانی نمی‌شوند.

## اجرای رابط روی رایانه برای توسعه
```bash
python -m pip install -r requirements.txt
python main.py
```
نیازمند محیط گرافیکی است. ذخیرهٔ فایل در اجرای رایانه در پوشهٔ خصوصی Kivy انجام می‌شود. قبل از ارسال نسخهٔ اندروید باید نمایش متن‌های ترکیبی فارسی/نماد، لمس ردیف‌های بازیافتی، توقف و بازگشت از پس‌زمینه و انتخابگر ذخیره روی دستگاه آزمایش شود.

## اجرای تست‌ها
برای تست غیرگرافیکی فقط `numpy pandas requests` لازم است:
```bash
python -m unittest discover -s tests -v
python -m py_compile main.py mobile_core.py futures_engine.py
```

## محدودیت‌ها و احتیاط
- «فعال» دستور معامله نیست؛ «آماده» نیازمند ماشه و ارزیابی مجدد است.
- هدف پیش‌فرض ۳٪ یک سناریوی حرکت قیمت بدون اهرم است، نه تضمین سود یا زمان وصول.
- R/R کارمزد تیکر را لحاظ می‌کند؛ فاندینگ، لغزش، عمق سفارش و لیکوییدشدن مدل نشده‌اند. قواعد بک‌تست سودآوری نشده‌اند.
- اسکن ترتیبی است و ممکن است چند دقیقه طول بکشد؛ نتایج هم‌زمان نیستند و باید پیش از اقدام دوباره بررسی شوند.
- دسترسی به API تابع شبکه و محدودیت‌های جغرافیایی/صرافی است. قطع دسترسی نباید نتیجهٔ «نبود فرصت» تلقی شود.
- برنامه گزارش را خودکار به سرور دیگری ارسال نمی‌کند؛ برای دریافت داده به API عمومی KuCoin متصل می‌شود.
- برنامه گزارش قبلی را در شروع اسکن جدید از نمایش پاک می‌کند؛ آخرین فایل ذخیره‌شده تا ذخیرهٔ موفق بعدی ممکن است متعلق به اجرای قبلی باشد. زمان گزارش را بررسی کنید.

## فایل‌ها
- `main.py`: رابط Kivy و ذخیره‌سازی اندروید با Storage Access Framework.
- `mobile_core.py`: مدیریت نخ اسکن، تبدیل تنظیمات فارسی و خروجی گزارش.
- `futures_engine.py`: کپی مستقل هستهٔ فیوچرز نسخهٔ ویندوز، بدون واردکردن ماژول‌های قدیمی.
- `buildozer.spec`: تنظیمات ساخت اندروید.
- `.github/workflows/android.yml`: ساخت دستی debug در GitHub Actions.
- `assets/DejaVuSans.ttf` و `assets/FONT_LICENSE.txt`: فونت و مجوز آن.
